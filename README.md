## Updating Checkout URLs (2-Minute Setup)

Once you publish your Gumroad product pages using the ready-to-paste copy and `1280×720` covers in each product repo's `store/` folder, update the URLs in [`store-config.js`](./store-config.js) and push to `main`. GitHub Actions (`.github/workflows/pages.yml`) automatically redeploys the site.
