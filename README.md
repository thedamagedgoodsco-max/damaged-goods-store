## Updating Checkout URLs & Domain Config

Once your Gumroad product pages are published using the copy and `1280×720` covers in each product repo's `store/` folder, or when updating domain/email settings, edit [`store-config.js`](./store-config.js) and push to `main`. GitHub Actions (`.github/workflows/pages.yml`) automatically redeploys the site.
